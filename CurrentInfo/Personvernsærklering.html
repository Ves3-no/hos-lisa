2. Hvilke opplysninger behandles?

Ved kjøp eller kontakt med nettbutikken kan vi behandle:

  • navn, e-postadresse, telefonnummer og leveringsadresse
  • bestillings-, produkt- og leveringsopplysninger
  • betalingsstatus og transaksjonsreferanse
  • opplysninger du sender i forbindelse med kundeservice, retur eller reklamasjon
  • tekniske opplysninger som er nødvendige for sikker drift av nettbutikken

Hos Lisa lagrer ikke fullstendige betalingskortopplysninger eller sikkerhetskoder.

3. Formål og rettslig grunnlag

  • Bestilling og levering: Opplysninger behandles fordi det er nødvendig for å oppfylle kjøpsavtalen.
  • Betaling: Stripe behandler nødvendige betalingsopplysninger for å gjennomføre og kontrollere betalingen.
  • Kundeservice, retur og reklamasjon: Opplysninger behandles for å følge opp avtalen og ivareta lovfestede rettigheter og plikter.
  • Regnskap og lovkrav: Opplysninger behandles når det er nødvendig for å oppfylle rettslige forpliktelser.
  • Sikkerhet: Begrensede tekniske opplysninger kan behandles når det er nødvendig for å sikre nettbutikken og forebygge misbruk.

4. Hvem kan få tilgang til opplysningene?

Opplysninger deles bare når det er nødvendig for å levere tjenesten, oppfylle lovkrav eller behandle betalingen:

  • Supabase: database og lagring av nettbutikkdata
  • Stripe: betalingsbehandling via Stripe Checkout
  • Netlify: hosting og levering av nettbutikken
  • Fraktselskap: navn, adresse og eventuelt telefonnummer for levering
  • E-postleverandør: nødvendig kommunikasjon om bestillinger og kundeservice

Leverandørene behandler opplysninger på vegne av Hos Lisa eller som selvstendige behandlingsansvarlige der dette følger av deres tjenester. Opplysninger selges ikke og brukes ikke til andre virksomheters egen markedsføring.

5. Lagringstid

Opplysninger lagres så lenge det er nødvendig for formålet de ble samlet inn for. Ordre- og regnskapsopplysninger oppbevares så lenge bokførings- og annet relevant regelverk krever det. Opplysninger som ikke lenger er nødvendige, slettes eller anonymiseres.

6. Betaling og leverandører

Betaling skjer via Stripe Checkout. Stripe kan behandle opplysninger i samsvar med sin egen personvernerklæring: stripe.com/privacy. Leverandører kan behandle personopplysninger utenfor EØS. Eventuelle overføringer skal ha gyldig grunnlag etter personvernregelverket.

7. Informasjonskapsler og lokal lagring

Nettbutikken bruker lokal lagring i nettleseren for å ta vare på innholdet i handlekurven. Vi bruker ikke analyse- eller markedsføringssporing utover det som eventuelt opplyses særskilt.

8. Dine rettigheter

Du kan blant annet be om innsyn, retting, sletting eller begrensning av behandlingen. Du kan også protestere mot behandling som bygger på berettiget interesse og be om dataportabilitet når vilkårene er oppfylt.

Rettighetene kan være begrenset når vi er rettslig forpliktet til å oppbevare opplysninger. Kontakt info@hoslisa.com for å bruke rettighetene dine. Vi svarer uten ugrunnet opphold og normalt senest innen én måned.

9. Klage

Dersom du mener at behandlingen er i strid med personvernregelverket, kan du kontakte oss. Du har også rett til å klage til Datatilsynet: datatilsynet.no.

10. Endringer

Denne personvernerklæringen kan oppdateres ved endringer i nettbutikken, leverandørene eller regelverket. Den gjeldende versjonen er tilgjengelig på nettbutikken.
